# Роли и права доступа

10 ролей в четырёх группах. Область видимости задаётся тремя параметрами: ресурс, территория (район, дом), организация.

## Принципы доступа

1. Персональные данные жителей видят только ЕРЦ, поставщик и ОСИ в пределах своей зоны. Акимат и аудитор получают данные по домам и районам без ФИО и номеров ЛС (Закон РК «О персональных данных и их защите»).
2. Каждая корректировка начисления проходит два шага: ИИ предлагает, оператор подтверждает, поставщик видит итог. Всё пишется в журнал действий.
3. Вход жителя: целевой — eGov (ЭЦП / eGov Mobile); в пилоте — имитация экрана eGov по тестовому ИИН. Модуль авторизации отделён для перехода на боевую интеграцию без переделки платформы.
