# Esepshy

Единый расчётный центр ЖКХ с ИИ-сверкой начислений и дистанционным учётом электроэнергии, тепла, воды и газа.

Проект ТОО «JASA Ltd» (Алматы) для программы G-TON Astana Hub. Задачи акиматов: ЕРЦ, учёт воды, учёт электроэнергии.

## Состав репозитория

| Путь | Что это |
| --- | --- |
| `index.html` | Кликабельный прототип (MVP) на демо-данных: сводка для акимата, ИИ-сверка, дистанционный учёт, задолженность, единая квитанция |
| `docs/roles.md` | Роли платформы и права доступа по модулям |
| `docs/user-scenarios.md` | Пользовательские сценарии по ролям (38 сценариев) |

## Прототип

Один самодостаточный HTML-файл без сборки. Открыть локально в браузере или задеплоить на Vercel как статический сайт.

Данные в прототипе синтетические: микрорайон «Самал-2», 12 домов, около 560 лицевых счетов, 12 месяцев. Тарифы демонстрационные.

## Модули платформы

1. Единая квитанция и онлайн-оплата
2. ИИ-сверка начислений (6 типов ошибок)
3. Дистанционный учёт: баланс «ввод в дом — сумма квартир», аномалии
4. Модель задолженности и сегменты риска
5. Панель KPI для акимата

## KPI пилота (из задач акимата)

| Показатель | Цель |
| --- | --- |
| Платежи онлайн | ≥ 70% |
| Ошибки в начислениях | ≤ 5 на 1 000 счетов |
| Умные счётчики воды и электроэнергии | 80% |
| Умные теплосчётчики | 70% |
| Потери воды | −15% |
| Потери электроэнергии | −10% |
